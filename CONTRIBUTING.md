# Contributing Guidelines

## Branches and Commits
- For branches that are being only worked on by one person, prefix their name, e.g. `konicai/improve-login-layout`
- Follow the commit message prefix convention described in Conventional Commits: https://www.conventionalcommits.org/en/v1.0.0/#summary
- Prefer PRs with relevant reviewers rather than pushing to master
- Avoid bypassing PR workflows
- Prefer "Squash and merge" or "Rebase and merge" rather than "Merge commit": https://docs.github.com/en/pull-requests/reference/pull-request-merges
  -  This helps keep a more linear git history which is easier to follow and understand

## Tracking work
- When contributing sizable big fixes or features, try to ensure there is an Issue for the work, and that it is inserted into the Kanban
